# Todo App with React + TypeScript

Простое Todo-приложение с возможностью управления списком задач, созданное на React с TypeScript.

## 🚀 Деплой

Приложение доступно по адресу: [https://oleg3es.github.io/todoList/](https://oleg3es.github.io/todoList/) 

## ✨ Функционал

- Добавление новых задач
- Отметка задач как выполненных/невыполненных
- Фильтрация задач: Все/Активные/Завершенные
- Счетчик оставшихся задач
- Очистка выполненных задач
- Возможность отметить все задачи сразу
- Адаптивный дизайн
